# 资源文件目录

这个目录包含Clock 3应用所需的所有资源文件。

## 必需的文件

### 声音文件
- `alarm.mp3` - 闹钟铃声（需要用户自己添加）
- `notification.mp3` - 通知声音（可选）

### 图像文件
- `icon.png` - 应用图标（128x128像素）
- `pet_default.png` - 默认宠物图标（100x100像素）

## 如何添加声音文件

1. 找一个合适的MP3文件作为闹钟铃声
2. 将其重命名为`alarm.mp3`
3. 放在这个目录中

或者使用系统默认声音，修改`app/main.py`中的`play_alarm_sound`方法。

## 备用方案

如果没有MP3文件，应用会显示警告但不会崩溃。
可以修改代码使用系统通知声音或震动代替。
